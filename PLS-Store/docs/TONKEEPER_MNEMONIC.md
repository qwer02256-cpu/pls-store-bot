# AutoStars 2.4: Tonkeeper с 12 словами

Добавлена отдельная REST-интеграция с **Fragment API Space**:
`https://api.fragment-api.space`. По документации провайдера поддерживаются
12 слов **BIP39 / V5R1**, 24 слова TON, оплата в TON. Это самостоятельный
сторонний сервис; принадлежность Telegram, Fragment или Tonkeeper не заявляется.
Старое подключение `api.fragment-api.com` оставлено для существующих установок.

## Установка

1. Остановите продажи и завершите активные заказы.
2. В магазине: `/admin` → Товары → AutoStars → **Файл, версия и инструкция** →
   **Обновить файл плагина**. Загрузите `plugins/AutoStars.py` версии 2.4,
   затем обновите TXT-инструкцию файлом `docs/AUTOSTARS_INSTALL.txt`.
   Для встроенной поставки обновите репозиторий и перезапустите магазин.
3. Скачайте обновление через **Лицензии** с прежним ключом. Магазин встраивает
   URL и публичный ключ лицензирования. Сырой `.py` репозитория нельзя просто
   положить в Cardinal: в нём незаполненные параметры лицензирования.
4. Остановите Cardinal, замените файл, запустите его. Обновление магазина
   не обновляет файлы Cardinal покупателей автоматически.
5. В Telegram-боте Cardinal: `/autostars` → **Настройки → Токен →
   Tonkeeper · 12 / 24 слова**. Прочитайте предупреждение и отправьте
   **ПОДКЛЮЧИТЬ**. При отмене — `/cancel`.
6. Отправьте публичный адрес из Tonkeeper → Получить. Затем в этом же боте
   введите свои 12 слов в исходном порядке. Не отправляйте их в магазин,
   поддержку, GitHub или чат с разработчиком. API проверяет адрес и определяет
   индекс BIP39-аккаунта. Для 12 слов требуется V5R1.
7. После подтверждения сверьте показанный адрес с Tonkeeper. Баланс смотрите
   в Tonkeeper: автопроверка баланса в новом режиме не реализована.
8. Проведите контролируемый заказ от 50 Stars и проверьте фактическую выдачу.
   Только после этого включайте обычные продажи. Проверьте комиссии и лимиты
   провайдера; доступность и актуальные тарифы не гарантируются плагином.

API-ключ, номер телефона и JWT для нового подключения не нужны.
Не дополняйте 12 слов до 24. TON mnemonic и BIP39 — разные схемы восстановления;
одинаковое количество слов само по себе не делает кошельки совместимыми.

## Куда попадает фраза

Новый провайдер **получает seed и подписывает переводы**. Это даёт ему доступ
к средствам. Подключение требует явного выбора и согласия в интерфейсе Cardinal.
Используйте отдельный рабочий кошелёк с небольшой суммой. Base64 не шифрует seed;
защиту передачи обеспечивает HTTPS. Перенаправления HTTP отключены.

Для автоматических покупок фраза хранится на хостинге Cardinal в
`storage/plugins/AutoStars/wallet_credentials.json` с правами `600`, без
шифрования на диске. Защищайте хостинг и резервные копии. В обычные настройки,
журнал покупок, сообщения с ошибками и журналы приложения seed не записывается.
Сообщение с фразой удаляется по возможности, но копии в Telegram могут остаться.

Сервер лицензий PLS Store получает только ключ, FunPay ID и продукт.
Он **не получает** seed, JWT Fragment, кошелёк и API-ключ. Режим лицензии с
12-часовым запасом сохраняется. Удаление подключения стирает локальные
реквизиты администратора, но не отзывает известную стороннему сервису фразу.

## Если покупка зависла

Прежде чем POST уйдёт в API, плагин атомарно фиксирует заказ FunPay в
`storage/plugins/AutoStars/provider_orders.json`. Затем сохраняется `request_id`.
Повторное событие заказа, перезапуск или повторное подтверждение **не создают
второй POST**. При потере ответа без `request_id` заказ блокируется для сверки.
При недоступном диске запрос не отправляется.

Только `completed` без отрицательного результата означает успех.
`queued`, `processing`, ошибки, timeout и неизвестные ответы требуют ожидания
или сверки. Автоповтор и автоматический возврат для отправленного заказа
блокируются, включая команду `!бэк`. Кнопка **Запросы покупок** показывает
FunPay order_id, состояние и request_id. Покупатель может отправить `+` в
FunPay: проверяется существующий запрос; после перезапуска очередь берётся
из сохранённого журнала при сообщении покупателя.

При потерянном ответе/ошибке проверьте историю TON и факт получения Stars.
Передайте в поддержку API только request_id и сведения заказа, без seed.
Если нужна новая покупка или возврат, сначала проведите ручную сверку;
возврат можно сделать вручную через FunPay. Не удаляйте журнал ради повтора.
Это защита от повторной отправки внутри одной установки с сохранённым диском,
а не гарантия провайдера: одновременный запуск нескольких копий Cardinal с
одним магазином/кошельком не поддерживается. Фоновая сверка не реализована.

## Что проверено

Есть автоматические тесты REST-контракта с подставными ответами: 12 слов без
изменения, проверка V5R1/BIP39, закрытый файл, восстановление request_id,
потеря ответа, сбой диска, неопределённые статусы и запрет повторной оплаты
и автоматического возврата. Среда разработки блокирует доступ к домену
провайдера (`403` прокси); живое подключение и покупка не проверены.
Доступность сервиса и фактическую отправку необходимо проверить с хостинга.
