AutoReviewReply 1.0.0 — ответы на отзывы FunPay

Что делает
После НОВОГО отзыва с 5 звёздами плагин размещает ответ продавца
под этим отзывом на FunPay. Название купленного лота получает из заказа:

Спасибо за заказ и отзыв! 💜

🛍 100 Telegram Stars

На отзывы с 1–4 звёздами не отвечает. Если покупатель изменил оценку
с 1–4 на 5, плагин может ответить после получения события об изменении.
Если вы уже ответили вручную, ответ не заменяется.
Название берётся из покупки: отдельный список лотов заполнять не нужно.
Цена, ключи, подробное описание и данные покупателя в ответ не вставляются.
Обычные эмодзи поддерживаются, Telegram-стикеры в FunPay не отправляются.

Установка
1. Загрузите AutoReviewReply.py в папку plugins вашего FunPay Cardinal.
   Это плагин Cardinal, а не Telegram-магазина. Дополнительные библиотеки,
   ключ API и отдельный сервер не нужны: используется вход Cardinal в FunPay.
2. Перезапустите Cardinal. Проверьте, что плагин активен в списке плагинов.
3. В Telegram-боте управления Cardinal отправьте /reviewreply.
   Панель также открывается стандартной кнопкой настроек плагина.
4. Плагин изначально включён. Отключите другие плагины/правила ответов
   на отзывы, чтобы два обработчика не меняли один и тот же ответ.
5. После следующего настоящего отзыва с 5 звёздами откройте отзыв на FunPay.
   Ответ должен появиться под ним. В журнале Cardinal будет номер заказа
   и сообщение об отправке. На настоящем аккаунте этот выпуск ещё не проверен;
   локальные тесты выполняются без отправки сообщений и ответов на FunPay.

Настройка текста
/reviewreply → Изменить текст ответа.
Отправьте, например:

Спасибо за заказ! Будем рады видеть вас снова 💜

🛍 {lot_title}

{lot_title} — обязательная переменная. Плагин подставляет реальное название
купленного лота. Других переменных нет. Ответ — обычный текст, HTML-теги
не нужны. Отмена ввода — кнопкой «Отменить ввод»; также поддержан /cancel,
если его не перехватил другой плагин. Стандартный текст восстанавливается
отдельной кнопкой. Текст меняется только для следующих ответов.
Длинное название сокращается, общий размер ответа ограничен 1000 символами.

Как включить или остановить
/reviewreply → Включить / Выключить.
Во время выключения новые отзывы в очередь не добавляются.
Отзывы, уже находившиеся в очереди до выключения, продолжат обработку
после включения. Уже начатый запрос в FunPay отменить нельзя.

История и повторные попытки
Настройки и номера обработанных заказов сохраняются здесь:
storage/plugins/AutoReviewReply/state.db
Не удаляйте этот файл при обновлении. После перезапуска плагин проверяет
наличие ответа перед повторной попыткой. При сбое сети — до 5 попыток
с увеличивающейся паузой. При потерянном ответе сервера сначала читается
состояние отзыва, чтобы не отправлять ответ повторно.
После 5 ошибок задача остаётся в журнале SQLite со статусом failed.
Номер заказа и попытки видны в логах; проверьте доступ к заказу и при
необходимости ответьте вручную. Токены и ответы HTTP в логи не выводятся.

Ограничения
Старые отзывы из профиля массово не сканируются: нужны события Cardinal.
При запуске возможно получение ранее не обработанного события из истории
чата — такой отзыв тоже будет проверен. Поддерживается FunPayAPI с методами
get_order и send_review и типами NEW_FEEDBACK / FEEDBACK_CHANGED.
Если другая программа ответила одновременно между чтением отзыва и отправкой,
FunPay не даёт атомарно запретить перезапись: используйте один обработчик.
Название берётся из сохранённого заказа и может отличаться от текущего
названия лота после его редактирования продавцом.
