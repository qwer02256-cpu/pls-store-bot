# Единый стиль плагинов PLS Store

Образец реализован в AutoStars.py. Другие плагины нужно привести к этому же
оформлению при добавлении их исходников в проект.

- Шапка панели: `PLS Store · Название плагина`, разделитель, заголовок экрана.
- Главное меню: две кнопки в строке; настройки/сообщения синие, лоты/финансы
  зелёные; инструкция отдельной строкой, возврат последней красной кнопкой.
- Синий `primary`: навигация по разделам и редактирование параметров.
- Зелёный `success`: создание, добавление, подтверждение и включение.
- Красный `danger`: возврат, отмена, удаление и отключение.
- Короткие подписи, одинаковые иконки и расположение кнопок возврата.
- Сохранять callback_data, бизнес-логику, настройки, обработчики и проверку лицензии.

AutoStars сериализует поле Bot API `style` в `_PlsButton.to_dict()`, поэтому
ему не нужен новый аргумент конструктора pyTelegramBotAPI. Это сохраняет
совместимость с более старыми версиями библиотеки на хостингах Cardinal.
Цвета видны в клиентах Telegram, поддерживающих цветные inline-кнопки.
