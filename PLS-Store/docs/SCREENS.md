# Очистка экранов магазина

При переходах по меню, открытии лицензий и ответах на команды магазин
отправляет новый экран и удаляет предыдущий. Входящее сообщение с командой
или введёнными данными также удаляется после успешной отправки ответа.
Номера экранов хранятся в `chat_screens`, поэтому перезапуск не сбрасывает
очередь очистки. Два сообщения длинного экрана (баннер и текст) очищаются вместе.

Выданные документы, плагины и инструкции остаются в чате. На экране статуса
счёта сохраняются кнопки оплаты и проверки. Переход «Назад» в главное меню
отменяет незавершённый ввод. Если отправка нового экрана не удалась, старый
сохраняется. Сетевые ошибки удаления повторяются при следующем переходе.
Если Telegram окончательно запрещает удаление (например, из-за возраста
сообщения), бот пытается снять его кнопки. Произвольная старая история,
созданная до этого обновления, не сканируется: Telegram Bot API не предоставляет
метод чтения истории чата. При нажатии старой кнопки её исходное сообщение
также попадает в очистку.

В `/admin` → Лицензии теперь есть карточки с кнопками блокировки, разблокировки,
сброса FunPay и журнала. Сброс через кнопку требует подтверждения. Список
в первую очередь показывает лицензии с запросами смены привязки.

Команда `/license_action 1 reset` сбрасывает лицензию **№1**. Её аргумент —
номер лицензии, а не FunPay ID и не Telegram ID. Поиск по FunPay ID выполняется
командой `/license FUNPAY_ID`; затем нужно выбрать найденную карточку.
Ошибки команды теперь объясняют это различие и показывают пример.

Для запуска обновите `main` и перезапустите магазин на BotHost. Новых переменных
не требуется. Таблица очистки добавляется при обычном запуске миграций.
