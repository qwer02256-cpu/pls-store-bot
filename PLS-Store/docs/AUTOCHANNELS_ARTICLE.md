# AutoChannels — выдача Telegram-каналов на FunPay

AutoChannels готовит Telegram-каналы по тарифам и выдаёт их покупателю после оплаты на FunPay. Управление — в боте FunPay Cardinal. Цена в PLS Store — 399 ₽ за бессрочный ключ на один аккаунт FunPay. Исходный плагин Ch AutoDelivery переименован; настройки и склад сохраняются.

## Что умеет плагин


- Создание приватных Telegram-каналов, сохранение пригласительных ссылок и размещение в выбранной папке.

- Тарифы: ID услуги SMM-панели, количество подписчиков и целевой запас каналов.

- Подготовка склада заранее и создание недостающих каналов по заказу. Скорость зависит от Telegram и провайдера.

- Привязка конкретного числового ID лота FunPay к тарифу. Сопоставления по словам в названии больше нет.

- Выдача по количеству оплаченного заказа и передача владельца на username покупателя.

- Журнал заказов, защита от повторного события оплаты, строгая проверка покупателя и чата.

## Привязка по ID лота

В разделе «Лоты» укажите числовой ID своего предложения FunPay и выберите тариф. Плагин записывает уникальную метку #PLSCH в описание выбранного лота и проверяет сохранение. Если FunPayAPI передаёт ID в полном заказе, проверяется именно он; если ID отсутствует — используется метка из полного описания оплаченного заказа. Заголовки, ключевые слова и текст чата для определения лота не используются. Не копируйте метку в другие предложения. Старые привязки по словам необходимо добавить заново.

## Когда обрабатывается username

Плагин реагирует на @username только при наличии ожидающей передачи по оплаченному заказу привязанного лота, от того же FunPay-покупателя и в том же чате. В остальных чатах не отвечает и передачу не запускает. При нескольких ожидающих заказах укажите @username #НОМЕР_ЗАКАЗА. Username продавца и сообщения других ботов игнорируются. Перед передачей повторно проверяется статус оплаты и привязка.

## Что потребуется


- FunPay Cardinal, аккаунт продавца и административный доступ к его Telegram-боту.

- Собственные Telegram API ID/API Hash, аккаунт создателя каналов, QR-авторизация и пароль 2FA продавца для передачи владельца.

- Действующие URL/ключ SMM API v2, поддерживаемая услуга и средства для её оплаты. 399 ₽ оплачивают плагин, а не подписчиков.

- Telethon, requests и qrcode[pil]; хостинг должен сохранять настройки, сессию, склад и журнал.

- Передача владельца подчиняется ограничениям Telegram: свежая сессия, 2FA, приватность и лимиты могут задержать операцию.

## Лицензия и обновление

Бессрочный ключ на один FunPay-аккаунт. Первая успешная проверка привязывает его к FunPay ID. Магазин выдаёт файл AutoChannels.py, ключ и INSTALL.txt. При временном сбое проверки подписанное подтверждение действует до 12 часов от последней успешной проверки. Явный отказ, блокировка и чужой FunPay ID не дают льготного периода. API-ключи, Telegram-сессия и пароль 2FA не передаются серверу лицензий. Открытый Python не гарантирует невозможность обхода защиты.

## Безопасное обновление и спорные выдачи

Перед установкой остановите Cardinal, сохраните storage/plugins и session_channel.session, удалите старую копию ch_autodeliv.py из загрузки. Старые неоднозначные ожидания без номера заказа и покупателя автоматически не импортируются: их завершает продавец после проверки. При неопределённой передаче или перезапуске во время неё журнал требует ручной сверки владельца, а не повторной отправки. Плагин не гарантирует качество подписчиков, сроки услуг и отсутствие ограничений Telegram.
