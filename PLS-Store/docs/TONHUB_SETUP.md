# AutoStars: Tonhub и 24 слова

В версии 2.5 возвращён способ подключения из версии 2.3: основной Fragment API,
API-ключ, телефон, версия кошелька и мнемоника из **24 слов**. Поддержка 12 слов
и подключение Fragment API Space удалены. Лицензирование и запас на 12 часов
при недоступности сервера лицензий сохранены.

Для работы используйте **кошелёк Tonhub**. Установите приложение из официального
источника, создайте отдельный рабочий кошелёк и безопасно сохраните 24 слова.
Не дополняйте фразу из 12 слов. Новый кошелёк имеет отдельный адрес;
деньги из другого кошелька не переносятся автоматически.

## Подключение

1. В боте Cardinal: `/autostars` → **Настройки → Токен → Создать токен**.
2. Введите API-ключ основного провайдера из `fragment-api.com/dashboard`.
   Это не лицензия PLS Store и не токен Telegram-бота.
3. Введите телефон без `+`, затем фактическую версию кошелька Tonhub.
   В интерфейсе доступны W5/V5R1 и V4R2. Не выбирайте версию наугад;
   совместимость версии и доступность авторизации определяет провайдер.
4. Отправьте 24 слова в исходном порядке только в боте вашего Cardinal.
   При запросе провайдера подтвердите вход в Telegram.
5. После получения токена сверьте подключённый кошелёк и баланс у провайдера.
   Проведите контролируемый заказ от 50 Stars перед включением обычных продаж.

Авторизация передаёт фразу внешнему Fragment API. Используйте отдельный
кошелёк с рабочей суммой. В магазин, поддержку или GitHub фразу не отправляйте.
Сервер лицензий её не получает. Совместимость живого кошелька и покупка
не проверялись из среды разработки.

## Обновление с 2.4

- Остановите продажи и разберите незавершённые покупки старого провайдера.
  Сверьте историю TON и получение Stars. После замены файла старая очередь
  больше не опрашивается. Не повторяйте платежи без сверки.
- Обновите магазин на BotHost. Если в каталоге используется загруженный вручную
  файл, обновите его через `/admin` → Товары → AutoStars → **Файл, версия и
  инструкция**, вместе с `docs/AUTOSTARS_INSTALL.txt`.
- Скачайте обновление через **Лицензии**: магазин встроит параметры проверки.
  При остановленном Cardinal замените `.py`, затем запустите его.
- Старое подключение Space сбрасывается, обработка плагина выключается.
  Подключите Tonhub через основной API и включите обработку вручную.
  Действующие JWT основного API и остальные настройки сохраняются.
- `wallet_credentials.json` и `provider_orders.json` в
  `storage/plugins/AutoStars/` автоматически не удаляются. После сверки
  сохраните журнал покупок и удалите больше не нужный файл с seed, включая
  резервные копии. Удаление не отзывает фразу у прежнего сервиса.

Полное руководство по лотам, выдаче и настройкам: [AUTOSTARS_INSTALL.txt](AUTOSTARS_INSTALL.txt).
