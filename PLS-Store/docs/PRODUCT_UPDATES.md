# Обновление плагина и комплект выдачи

После обновления кода магазина и перезапуска на BotHost:

1. Откройте `/admin` → **Товары** → нужный плагин.
2. Нажмите **Файл, версия и инструкция** → **Обновить файл плагина**.
3. Отправьте новую версию `.py` размером до 2 МБ. Имя обычного плагина сохраняется;
   для товара AutoStars используется `AutoStars.py`.
4. Файл проверяется как UTF-8 и Python-синтаксисом, но не запускается на сервере.
   Если в коде есть литерал `VERSION = "2.3"`, версия каталога обновится вместе
   с файлом. Если версии нет или она вычисляется кодом, бот попросит её ввести.
   До ввода версии прежний файл продолжает выдаваться покупателям.
5. **Обновить TXT-инструкцию** принимает UTF-8 `.txt` до 100 КБ или текст.
   Загружайте установку и настройку функций именно этой версии плагина:
   внешние подключения, лоты, переключатели, примеры и диагностику.
6. **Скачать инструкцию** позволяет проверить файл, который получит покупатель.
   **Изменить версию** меняет только подпись версии каталога, не код плагина.

Файл и версия публикуются одной транзакцией. Ошибочный Python не заменяет
рабочий файл. Старые версии на диске не удаляются; для отката можно загрузить
прежний `.py` заново. Проверка синтаксиса не является анализом безопасности:
администратор загружает доверенный код.

Для AutoStars обязательна встроенная проверка лицензии PLS Store. Переименование
исходной версии без защиты не обходит эту проверку загрузчика. Можно загрузить
как исходник с шаблоном адреса, так и защищённый файл, ранее скачанный через
магазин: встроенный адрес нормализуется и при новой выдаче заменяется текущим
`LICENSE_PUBLIC_BASE`. Это сохраняет актуальный адрес проверки после смены домена.

## Комплект покупателя

- `ИмяПлагина.py` — текущая версия плагина;
- ключ — текстом в сообщении бота, без отдельного файла;
- `INSTALL.txt` — подробная инструкция по подключению и функциям плагина.

Для AutoStars ключ из сообщения вводится в Telegram-боте Cardinal через
`/autostars` → **Ввести ключ**. Плагин сам создаёт локальный `license.json`.
Отдельный JSON-файл теперь не является частью выдачи. Ранее установленный
`license.json` продолжает работать; его не нужно удалять при обновлении.

Прежние покупатели открывают **Лицензии** → свою лицензию → **Скачать**.
Они получают текущие файлы; ключ, FunPay ID и статус лицензии сохраняются,
повторной покупки нет. Код на хостинге Cardinal сам не обновляется: покупатель
останавливает Cardinal, заменяет `.py`, сохраняет настройки и запускает его.

## Встроенная инструкция AutoStars

`AUTOSTARS_INSTALL.txt` — полное руководство по функциям: установка, подключение
Fragment, кошелёк и токен, LOT_ID и количество Stars, запуск и остановка лотов,
выдача и очередь, !бэк и автовозврат, пороги TON, расчёт финансов, шаблоны
сообщений, предпродажный автоответчик, прокси, первый тест и диагностика.
Активация ключа вынесена в короткое приложение в конце.

При запуске магазина прежняя стандартная инструкция заменяется новой только
при точном совпадении с известным встроенным текстом. Собственные инструкции
администратора сохраняются. Для другого плагина нужно загрузить его собственную
инструкцию; магазин не выдумывает настройки неизвестного исходника автоматически.
При изменении функций нового релиза обновляйте TXT вместе с `.py`.
