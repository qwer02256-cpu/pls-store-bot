# AutoSMM — автоматизация SMM-заказов на FunPay

AutoSMM связывает магазин на FunPay с SMM-панелями API v2: помогает подготовить лоты, принять ссылку покупателя и передать оплаченный заказ в панель. Управление — в Telegram-боте FunPay Cardinal. Цена PLS Store — 349 ₽ за бессрочный ключ на один аккаунт FunPay.

## Возможности


- Подключение нескольких SMM-панелей API v2 с собственными URL, ключами и параметрами прокси.

- Ручная привязка существующих лотов, создание новых и массовая выгрузка поддерживаемых услуг.

- Шаблоны заголовков и описаний, тег #SMM для распознавания заказа.

- Расчёт цены с наценкой, конвертацией валют, контролем себестоимости и минимальной прибыли.

- Получение ссылки и подтверждения покупателя, очередь, статусы и проверка спорных запусков.

- Рефилл по доступности услуги и настройкам продавца, контроль баланса, статистика и резервные копии.

## Как проходит заказ

Покупатель оплачивает лот на FunPay и передаёт ссылку. После проверки ссылки, подтверждения, количества, оплаты и средств плагин отправляет заказ в панель. Для автозапуска поддерживаются типы Default и Poll. При неопределённом ответе запуск требует сверки с историей панели: повторный запрос вслепую может создать второй платный заказ.

## Что потребуется


- Работающий FunPay Cardinal и доступ администратора к его Telegram-боту.

- Собственный аккаунт SMM-панели с API v2, конечный адрес API и действующий API-ключ.

- Средства на балансе панели: 349 ₽ оплачивают плагин, а не выполнение услуг.

- Сетевой доступ с хостинга Cardinal к FunPay, панели, Telegram и серверу проверки лицензий.

- Проверка совместимости API конкретного провайдера; одинаковое обозначение API v2 не гарантирует поддержку всех параметров.

## Начало работы


- Скачайте AutoSMM.py, ключ PLS-… и INSTALL.txt в PLS Store. Остановите Cardinal, сохраните резервную копию storage/cache и замените файл в plugins/.

- После входа Cardinal в нужный FunPay откройте /auto_smm_settings и активируйте ключ.

- Добавьте панель по конечному API URL и ключу, проверьте каталог, валюту и баланс.

- Привяжите один лот к услуге и количеству, проверьте #SMM-тег, домены ссылок, цену и настройки возврата.

- Проведите один контролируемый заказ. Сверьте номер и результат в панели, затем расширяйте каталог. Массовая выгрузка действительно меняет лоты на FunPay.

## Лицензия и обновления

349 ₽ — бессрочная лицензия на один FunPay-аккаунт. Первая успешная активация привязывает ключ к FunPay ID. Магазин автоматически выдаёт файл, ключ и инструкцию; повторное скачивание — в разделе «Лицензии». При временном сбое проверки подписанное подтверждение действует до 12 часов от последней успешной проверки. Блокировка, чужой FunPay ID и явный отказ не дают льготного периода. Защита в открытом Python не гарантирует невозможность обхода.

## Данные и ограничения

API-ключи и настройки панелей остаются на хостинге Cardinal. На сервер лицензий передаются только ключ PLS, FunPay ID и код товара. Плагин не гарантирует качество, сроки и восстановление услуг стороннего провайдера; рефилл зависит от панели и правил услуги. Соблюдайте условия FunPay, провайдера и площадки назначения. Фоновая остановка /stop_smm не снимает лоты с продажи: для этого предусмотрена отдельная кнопка.
