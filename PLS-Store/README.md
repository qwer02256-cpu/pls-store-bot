# PLS Store v8 — Platega + баланс + дизайн (фундамент)

## Что в этом архиве

### ✅ Готово и подключено
- **services/platega.py** — клиент официального API Platega  
  (`POST /transaction/process`, `GET /transaction/{id}`, проверка колбэка по заголовкам `X-MerchantId` / `X-Secret`)
- **services/db.py** — безопасные миграции SQLite, таблицы:
  - `users` (баланс, потрачено, покупки, рефералы)
  - `payments` (история пополнений Platega)
  - `purchases` (история покупок)
  - `balance_log` (журнал изменений баланса)
  - `faq`, `promos`
  - настройки дизайна в `bot_settings`
- **services/ui.py** — клавиатуры главного меню, профиля, сумм пополнения (тексты из БД)
- **handlers/payments.py** — создание платежа, проверка статуса, идемпотентное зачисление
- **.env.example** — все переменные
- Оригинальный **main.py** — каталог, карточки товаров, админка товаров/заявок/баннера **без изменений**

### ⏳ Нужно дописать в следующем шаге (в main.py)
1. Импорт и регистрация `handlers.payments.router`
2. Новый экран профиля (баланс, кнопки)
3. Покупка товара с баланса
4. FAQ + редактор в админке
5. Раздел «🎨 Настройка дизайна»
6. HTTP-колбэк для Platega (aiohttp)

Старая функциональность (товары, заявки, админка) **работает сразу** после замены файлов.

## Установка

1. **Сделайте резервную копию** папки проекта и файла `data/store.db`.

2. Распакуйте архив **поверх** текущей папки PLS-Store.  
   Папку `data/` **не удаляйте** — база сохранится, миграции добавят только новые таблицы.

3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Создайте `.env` (или пропишите переменные на хостинге):
   ```bash
   cp .env.example .env
   ```
   Заполните:
   ```
   BOT_TOKEN=...
   ADMIN_ID=ваш_telegram_id
   SUPPORT_USERNAME=...
   REVIEWS_URL=...
   DB_PATH=data/store.db

   # Platega (https://docs.platega.io)
   PLATEGA_MERCHANT_ID=uuid-из-кабинета
   PLATEGA_SECRET=секрет-из-кабинета
   PLATEGA_CALLBACK_BASE=https://ваш-публичный-https-домен
   PLATEGA_CALLBACK_PORT=8080
   ```

5. В личном кабинете Platega: **Настройки → Callback URLs**  
   укажите:
   ```
   https://ваш-домен/platega/callback
   ```
   (колбэк-сервер будет добавлен в следующем обновлении main.py)

6. Запуск:
   ```bash
   python main.py
   ```

## Подключение Platega (кратко)

| Параметр | Где взять |
|----------|-----------|
| MerchantId | Кабинет Platega → Настройки |
| Secret | Кабинет Platega → Настройки |
| Callback URL | Публичный HTTPS (требования Platega: только HTTPS, валидный сертификат) |

Метод создания платежа: `POST https://app.platega.io/transaction/process`  
Заголовки: `X-MerchantId`, `X-Secret`  
Статусы колбэка: `CONFIRMED` (зачислить), `CANCELED` (не зачислять).

Документация: https://docs.platega.io/
