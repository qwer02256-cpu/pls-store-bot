# PLS Store

Telegram-магазин цифровых товаров на **aiogram 3** + **SQLite** + **Platega**.

[![Python 3.10+](https://img.shields.io/badge/python-3.10+-blue.svg)](https://www.python.org/downloads/)
[![aiogram 3](https://img.shields.io/badge/aiogram-3.x-blue.svg)](https://docs.aiogram.dev/)

## Возможности

- 🛒 Каталог товаров с карточками, фото, описанием, статьёй и видео
- 💳 **Platega** — пополнение внутреннего баланса (СБП / карты)
- 👤 Профиль: баланс, потрачено, покупки, рефералы
- 🛒 Покупка с баланса (автоматическая) + ручные заявки
- 🔗 Реферальная система (% от пополнений)
- 🎟 Промокоды
- ❓ FAQ с краткими ответами и отдельной страницей «📄 Документы» (политика конфиденциальности, пользовательское соглашение, товары и тарифы)
- 🎨 Полностью настраиваемые тексты кнопок и разделов через админку
- 🖼 Баннеры для главного меню, профиля, магазина, FAQ, пополнения
- 🛠 Админ-панель: товары, заявки, платежи, пользователи, балансы, покупки, промо, FAQ, дизайн

## Быстрый старт

```bash
git clone https://github.com/YOUR_USER/PLS-Store.git
cd PLS-Store
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
# заполните .env
python main.py
```

## Переменные окружения

| Переменная | Описание |
|------------|----------|
| `BOT_TOKEN` | Токен бота от @BotFather |
| `ADMIN_ID` | Ваш Telegram user ID |
| `SUPPORT_USERNAME` | Username поддержки (без @) |
| `REVIEWS_URL` | Ссылка на отзывы |
| `DB_PATH` | Путь к SQLite (по умолчанию `data/store.db`) |
| `PLATEGA_MERCHANT_ID` | UUID мерчанта из кабинета Platega |
| `PLATEGA_SECRET` | Секретный ключ Platega |
| `PLATEGA_CALLBACK_BASE` | Публичный HTTPS URL (например `https://bot.example.com`) |
| `PLATEGA_CALLBACK_PORT` | Порт локального HTTP-сервера колбэков (по умолчанию `8080`) |

См. `.env.example`.

## Platega

1. Получите `MerchantId` и `Secret` в [кабинете Platega](https://platega.io).
2. Укажите Callback URL:
   ```
   https://ваш-домен/platega/callback
   ```
3. Бот поднимает aiohttp-сервер на `PLATEGA_CALLBACK_PORT` и принимает POST с заголовками `X-MerchantId` / `X-Secret`.
4. При статусе `CONFIRMED` сумма идемпотентно зачисляется на баланс пользователя.

Официальная документация: https://docs.platega.io/

## FAQ и документы

В пользовательском разделе FAQ показываются краткие ответы и кнопка «📄 Документы». На странице документов размещены внешние статьи:
- Политика конфиденциальности
- Пользовательское соглашение
- Товары и тарифы

Ссылки открываются непосредственно через URL-кнопки Telegram.

## Админ-команды

| Команда | Описание |
|---------|----------|
| `/admin` | Панель управления |
| `/addpromo CODE 100 [лимит]` | Создать промокод на сумму |
| `/reply USER_ID текст` | Ответить пользователю |

В `/admin` доступны:
- Товары (создание, редактирование, скрытие)
- Заявки
- Платежи, пользователи, покупки
- Ручная корректировка балансов
- FAQ, промокоды
- **🎨 Дизайн** — тексты кнопок и разделов
- **🖼 Баннеры** — загрузка изображений для разделов

## Миграции

База обновляется автоматически при старте (`CREATE TABLE IF NOT EXISTS` + `ALTER TABLE` для новых колонок).  
Существующие товары и заявки **не удаляются**.

### Premium Emoji в кнопках

Для Premium Emoji в кнопках требуется aiogram 3.25.0 или новее и Telegram Bot API 9.4+.
Откройте `Админ-панель → Дизайн → нужная кнопка` и отправьте сообщение с Premium Emoji
(можно вместе с текстом). Бот сохранит ID эмодзи отдельно и передаст его в поле
`icon_custom_emoji_id`, чтобы Telegram показывал эмодзи как иконку слева от текста кнопки.
Владелец бота должен иметь Telegram Premium (либо бот должен соответствовать условию
с дополнительными именами пользователя, приобретёнными через Fragment).
