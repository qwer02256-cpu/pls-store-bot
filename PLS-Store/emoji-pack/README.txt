PLS Store — White Emoji, 30 анимированных эмодзи

Файлы для Telegram: папка webm. Каждый файл: VP9, 100×100, 30 кадров/с,
2 секунды, прозрачный фон, без звука. RGB значков — белый. По значкам проходит диагональный белый блик.
PNG — статичные версии. SVG — векторные исходники.
preview.gif — анимированное превью на тёмной подложке (подложка только в превью).
manifest.json — порядок, названия и соответствующие обычные эмодзи.

Публикация:
1. Откройте официальный @Stickers в Telegram.
2. Отправьте /newemojipack, выберите тип Video / Видео.
3. Назовите набор PLS Store White.
4. Загружайте файлы webm как файлы/документы, без преобразования в видео.
5. Каждому назначайте соответствующий обычный эмодзи из manifest.json.
6. Отправьте /publish и задайте свободное короткое имя набора.
Интерфейс @Stickers может отличаться; следуйте его текущим подсказкам.

Набор ещё не опубликован. Приём файлов сервером Telegram требует проверки
при загрузке в @Stickers; локальные проверки не заменяют эту проверку.
После публикации можно получить custom_emoji_id и настроить их в боте.
Применение Premium Emoji зависит от действующих ограничений Telegram.

Контурные формы: Lucide 0.468.0 (ISC), лицензия приложена.
Анимация и сборка: подготовлены для PLS Store.

Повторная сборка: FFmpeg с libvpx-vp9 и Python 3.12+.
Установите requirements-build.txt и запустите python build.py.
