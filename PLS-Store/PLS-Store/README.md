# PLS Store

Telegram-магазин плагинов для FunPayCardinal. Заявки на покупку отправляются администратору; оплата и передача товара выполняются вручную.

## Переменные окружения

Настройте в панели хостинга:

- `BOT_TOKEN` — токен, полученный у `@BotFather`.
- `ADMIN_ID` — числовой Telegram ID администратора (в примере уже указан предоставленный ID).
- `SUPPORT_USERNAME` — username поддержки без `@`.
- `REVIEWS_URL` — ссылка на канал с отзывами (в примере уже указана предоставленная ссылка).
- `DB_PATH` — путь к SQLite базе (по умолчанию `data/store.db`).

Не публикуйте токен и не добавляйте `.env` в GitHub.

## Запуск

Python 3.11:

```bash
pip install -r requirements.txt
python main.py
```

На хостинге с Dockerfile достаточно выбрать этот репозиторий и настроить переменные окружения.

## Команды администратора

Добавить товар:

```text
/addproduct Название | 500 ₽ | Описание товара
```

Посмотреть товары:

```text
/products
```

Скрыть товар из каталога:

```text
/delproduct ID
```

Ответить покупателю:

```text
/reply TELEGRAM_ID Текст сообщения
```

Первый запуск создаёт SQLite-базу автоматически.
