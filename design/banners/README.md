# PLS Store: серия баннеров

12 баннеров, 1600×900, RGB PNG. Заголовки и подписи взяты из функций и разделов бота. Цены, проценты и динамические данные остаются в тексте Telegram.

| banner.png | Главное меню, /start после принятия условий |
| shop.png | Магазин, /catalog |
| plugins.png | Плагины для FunPayCardinal, включая пустой каталог |
| profile.png | Профиль, /profile |
| topup.png | Пополнение баланса и выбор способа пополнения |
| language.png | Выбор языка |
| faq.png | FAQ |
| documents.png | Документы, первый вход, /testdocs |
| support.png | Поддержка, /support |
| reviews.png | Отзывы |
| purchases.png | Мои покупки, включая пустую историю |
| referral.png | Реферальная система |

API пока в разработке, отдельная иллюстрация услуги не создаётся. Карточки товаров используют свои фото; административные таблицы и короткие служебные сообщения не требуют отдельных баннеров. Поддержка и отзывы сохраняют состояния «не настроено» в тексте. Баннеры на русском, как исходная графика; перевод текста и кнопок бота сохранён.

## Исходники и воспроизведение

- `sources/reference.png` — исходный баннер проекта, совпадающий с приложенным образцом.
- `sources/atlas-1.png` … `atlas-3.png` — сгенерированные иллюстрации без заголовков и фирменного блока, по четыре сцены. Исходные панели масштабируются до 1600×900.
- `sources/*-background.png` — отдельные фоны до наложения типографики.
- `brand-lockup.png` — единый прозрачный RGBA-блок: оригинальный логотип, разделитель и оригинальная надпись. Извлечён из reference, не перерисован генератором.
- `series.json` — тексты, расположение сцен и выходные имена.
- `fonts/` — зафиксированные DejaVu Sans Regular/Bold и лицензия.
- `../../tools/render_banners.py` — общий программный шаблон.
- `contact-sheet.jpg` — обзор всей серии.

Из корня репозитория: `python3 tools/render_banners.py` (Pillow 13.0.0). Pillow нужен только для сборки графики, не для работы бота. Скрипт проверяет ширину строк, нижнюю границу текста и совпадение наложения единого RGBA-блока и точное совпадение RGB всех его непрозрачных пикселей во всех экспортированных PNG. Стандартный тест бота: из `PLS-Store` выполнить `python -m unittest discover -s tests -v`.

Фиксированные параметры: поля текста x=72/76, заголовок 96 px Bold, подпись 48 px Regular, белый / #ddc6f4. Фирменный блок 480×140 px, x=72, y=56; верхний левый угол. Полупрозрачные края блока компонуются с фоном; непрозрачные пиксели идентичны во всей серии.

Для следующего баннера сгенерируйте фон без букв и логотипов: чёрно-фиолетовый фон, глянцевый фиолетовый 3D-объект справа, стеклянные карточки, неоновые волны. Оставьте левую половину и верхнюю левую область свободными. Добавьте сцену и реальные тексты в series.json, используйте общий шаблон; логотип не генерируйте заново.

При первом запуске новой версии прежние настройки `banner_<section>` однократно архивируются в `banner_<section>_before_series_2026_11`, после чего активируется встроенная серия. Сами загруженные файлы сохраняются. Последующие загрузки через админку снова имеют приоритет и сохраняются при перезапусках. Остальные настройки и данные магазина не затрагиваются. В журнале запуска появляется `Banner release: pls-purple-2026-11-v3 | available=12/12`. Чтобы применить изменения на BotHost, платформа должна получить новый код и перезапустить процесс; отправка в GitHub сама по себе не подтверждает развёртывание.
