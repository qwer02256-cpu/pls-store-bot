# PLS Store: полная серия баннеров

63 PNG: 21 экран × русский, английский и украинский. Все файлы — 1600×900, RGB.
Тёмный чёрно-фиолетовый фон, неоновые волны, глянцевые 3D-объекты и единая типографика.
Фирменный блок везде **справа сверху**: 480×140, x=1048, y=24;
правое поле 72 px. Это один и тот же исходный прозрачный RGBA-файл,
а не отдельная генерация логотипа для каждой иллюстрации.

украинские — в `assets/uk/`, с теми же именами.

Короткие ошибки и состояния переиспользуют изображение текущего раздела.
Длинный текст не обрезается: общий рендерер показывает баннер и отдельное текстовое
сообщение. При навигации пара сообщений редактируется, без удаления и его анимации.
Уведомления об оплате поддерживают фото тем же рендерером. Файлы плагинов и TXT
остаются отдельными документами. Индивидуальное фото товара имеет приоритет
над общим product.png. Цены, версии, баланс и идентификаторы не вшиты в картинки.

## Исходники

- `sources/reference.png` — исходный образец проекта.
- `brand-lockup.png` — извлечённый из оригинала логотип с разделителем и надписью,
  прозрачный RGBA. Форма и оригинальные цвета не перерисовываются.
- `sources/*-background.png` — 21 отдельная иллюстрация без наложенных логотипов
  и надписей. Девять новых сцен созданы инструментом генерации изображений.
- `sources/atlas-*.png` — сохранённые исходники прежних 12 сцен.
- `series.json` — реальные названия разделов и русские подписи.
- `translations.json` — все английские и украинские надписи.
- `layout.json` — общий шаблон размеров, полей, позиции бренда и текста.
- `fonts/` — фиксированные DejaVu Sans Regular/Bold и лицензия.
- `../../tools/render_banners.py` — воспроизводимое наложение.
- `contact-sheet.jpg`, `contact-sheet-en.jpg`, `contact-sheet-uk.jpg` — обзоры серии.
- `build-report-{ru,en,uk}.json` — список каждого файла, размер, SHA-256 и результат
  проверки общего слоя логотипа.

## Пересборка

Из корня репозитория:

```sh
python -m pip install -r design/banners/requirements.txt
python tools/render_banners.py
```

Pillow нужен только для сборки графики, не для работы бота. Скрипт не генерирует
надписи моделью: он накладывает один RGBA-блок и текст одинаковыми шрифтами.
Проверяются ширина строк, нижняя граница текста, размер каждого PNG, точное
соответствие альфа-композиции фирменного блока и равенство всех его непрозрачных
пикселей во всей серии. Для отдельного перевода можно указать `--languages en uk`;
`--only licenses` пересобирает одну сцену, после чего для полного отчёта следует
выполнить полную сборку.

Для следующей сцены создайте фон без букв, логотипов, цен и водяных знаков.
Левая половина должна оставаться тёмной и свободной; верхняя область под фирменный
блок — без объектов. Иллюстрация располагается справа ниже заголовочной полосы.
Добавьте реальные тексты на трёх языках в JSON и используйте существующий шаблон.

## Развёртывание

Список и приоритеты баннеров общие для main.py и обработчиков лицензий/маркетинга
в `services/banners.py`. В админке можно заменить любую из 63 картинок по языку.
При первом запуске этой серии прежние настройки баннеров сохраняются в
`banner_<section>[_<lang>]_before_right_63_v1` и включаются встроенные файлы.
Сами старые загруженные фото не удаляются. Последующие новые загрузки имеют
приоритет и сохраняются после перезапуска. Балансы и покупки миграция не меняет.

В логах запуска: `pls-purple-2026-11-v5-right-63 | available=63/63`.
Отправка в GitHub не подтверждает обновление BotHost: нужны получение нового
кода и перезапуск магазина. Заново откройте экран для перерисовки старого сообщения.
